# Prebuild Binaries for BSD 4.3

By policy, we do not include binaries on [GitHub](https://github.com).
(It's a **source** archive, damit!)

That said, unlike programs for modern Linux, Windows or macOS, BSD 4.3
binaries are not easy to find (or for that matter build from mdern
sources). Thus, it's convenient for this repository to point binaries
useful on BSD 4.3. 

* (C-Kermit for BSD
4.3)[https://www.kermitproject.org/ckbinaries.html#bsd], useful for FTP
on BSD 4.3 is overwhelmed by file sizes.  (If using
(Kermit)[https://www.kermitproject.org/], you will also want to look at
(Internet Kermit Service)[https://www.kermitproject.org/iksd.html] and
it's associated page for setting up a server at the remote end.)
